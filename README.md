# Instagram Unfollowers
## Author: Arnau Neches Vilà

### About:

Simple extension to get a list of people who don't follow you back.

### Instalation:

- Download this repo and unzip it somewhere safe.
- Go to chrome://extensions/ (Or Configuration->Extensions).
- Activate "Developer mode" (Top right).
- Click on "Load unpacked" and select the folder you saved before.

### Use:

- Get into your instagram account profile page.
- Click on "Analyze Profile".
- If "Download lists" is checked, both "followers" and "following" lists will be downloaded.
- Wait and you will get downloaded an "unfollowers" list.
